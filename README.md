# Frame Lab · 相机拼图

直接用现代浏览器打开 `index.html` 即可使用，无需安装依赖或启动服务器。请保持 `index.html`、`style.css`、`app.js` 和 `assets` 文件夹的相对位置不变。

## 部署到 GitHub Pages

仓库只含静态文件，可直接以 Pages 方式上线：

1. 在 GitHub 新建一个仓库（Public，免费账号即可开通 Pages），不要勾选初始化 README。
2. 在本项目目录执行：

   ```bash
   git init -b main
   git add .
   git commit -m "Frame Lab 相机拼图工具"
   git remote add origin git@github.com:<用户名>/<仓库名>.git
   git push -u origin main
   ```

3. 打开仓库的 Settings → Pages，将 Source 设为 `Deploy from a branch`，分支选 `main` 和 `/ (root)`，保存。
4. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`。手机、电脑均可直接使用。

页面内所有资源使用相对路径引用，放在仓库子目录也能正常访问。更新时重新提交并推送即可；Pages 刷新通常在一分钟内完成。若使用自定义仓库名，无需修改任何代码。


## 使用

1. 点击上传区域或拖入照片。
2. 调整缩放和位置，也可以拖动预览下半部分的照片。屏幕和下方使用同一份构图，比例不同时屏幕以黑边适配。
3. 可选添加文字水印：开关默认关闭，默认位置右下角，支持九个位置、大小和不透明度。
4. 选择比例（3:4、9:16、1:1、4:3、16:9）、清晰度、布局（横版自动左右拼图）与格式后导出；手机可用「分享 / 保存到相册」。

比例、清晰度、布局、格式、虚化、相机大小和水印设置会保存在浏览器本地；照片和照片构图不会保存。

## 模板

模板来自提供的 1080 × 1440 参考图。上方 1080 × 720 保留相机和背景，屏幕四角坐标在 `app.js` 的 `screen` 中设置。屏幕内部以逐行映射方式替换，下方显示同一张裁切照片。默认示例取自参考图下半部分。

`assets/images.js` 内嵌模板及示例，支持直接以 file URL 打开页面并导出 Canvas 图片。PNG 模板和 JPG 示例也单独存放在 assets 中，供后续更换素材使用；更换后需同步重新生成内嵌资源。

大图导出仅提升输出像素尺寸，原相机模板不会获得额外细节。若有更清晰的相机模板，可替换素材并重新标定屏幕区域。
